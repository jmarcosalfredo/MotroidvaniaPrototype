# 📖 Overview

This project is Metroidvania prototype built in Unity with the goal of exploring gameplay programming, scalable architecture and RPG mechanics.

Instead of focusing only on level design, this prototype emphasizes reusable gameplay systems and clean code organization.

---

# ✨ Gameplay Features

- ⚔️ Melee Combat
- 💨 Dash
- 🧗 Wall Mechanics
- 👾 Enemy AI
- 🧙 Skill System
- 📦 Inventory System
- 🛡 Equipment System
- ❤️ Character Stats
- 💾 Save System
- 📍 Checkpoints
- 💬 NPC Interaction
- 🎮 Complete UI
- ✨ Visual Effects
